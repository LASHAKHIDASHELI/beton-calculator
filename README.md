# ბეტონის კალკულატორი

ბეტონის ღირებულების კალკულატორი — კლასი, რაოდენობა და მიწოდების მისამართი.

ტრანსპორტირება ითვლება რეისზე: ერთი მიქსერი ეტევა 12 მ³, ამიტომ რაც უფრო
დიდია შეკვეთა, მით უფრო იაფია 1 მ³.

```
რეისები = ceil(რაოდენობა / 12)
ჯამი    = რაოდენობა × კუბის ფასი + რეისები × ტრანსპორტირება
```

ფასი მოცემულია ბეტონის ტუმბოსა და ლაბორატორიის გარეშე.

ერთი ფაილი, დამოკიდებულებების გარეშე — `index.html`.
